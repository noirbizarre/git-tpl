## Installation

```bash
cargo install git-tpl
```

```bash
brew install noirbizarre/homebrew-tap/git-tpl
```

```bash
paru -S git-tpl-bin  # or your AUR helper of choice
```

Or download a binary for your platform from the
[latest release](https://github.com/noirbizarre/git-tpl/releases/latest).

## Usage

```bash
git-tpl --help
```
